## Практическая часть.

### Задача 1. Изучение платформы для юнит-тестирования

Освойте основы работы с платформой для разработки юнит-тестов, соответствующей
вашему рабочему стеку. В курсе все примеры приводятся на .NET, но вы можете выбрать
любой другой.
Ссылка на мануал от Майкрософт для начала работы с MSTest:
https://learn.microsoft.com/en-us/visualstudio/test/getting-started-with-unit-testing?view=vs-2022&tabs=dotnet%2Cmstest

Что необходимо знать (минимальный уровень) для работы с платформой юнит-тестирования (на примере MSTest)

Атрибуты:
TestClass
TestMethod
DataRow
DataTestMethod
TestInitialize
TestCleanUp

Методы класса Assert
• Assert.AreEqual — проверяет равенство двух значений.
• Assert.AreSame — проверяет, указывают ли ссылки на один и тот же объект.
• Assert.IsTrue — проверяет, что условие верно (true).
• Assert.IsNull — проверяет, что объект равен null.
• Assert.InstanceOfType — проверяет, соответствует ли объект указанному типу.
• Assert.ThrowsException<T> — проверяет, выбрасывает ли код исключение типа T

Результатом выполнения данного задания должен быть проект с тестами, в котором
использованы все вышеперечисленные атрибуты и методы. Тесты должны проходить, скрин
результатов прогона включается в отчет.
